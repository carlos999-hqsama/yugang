# App 设置与会话管理

使用内置 app_settings_get/update 与 app_sessions_list/delete/restore。只处理本 App，不读 Android 偏好文件、密钥或其他应用。公开设置仅任务期间保持唤醒；不能改模型 Key、地址或权限。

改设置或删除会话必须是用户明确要求。技能加载本身不授予权限，也不会改变默认且不可改的全访问契约；删除会话仍必须通过工具中的确认问答。先列精确目标，再按用户要求操作。回收站可恢复，不能用 shell 删除 .dsh 数据或永久清空。当前、运行中、后台活动或父子关联的会话不能删除，不绕过拒绝。只返回遮盖标题、编号与状态，不输出无关正文或凭据。

本地工作文件必须留在自己的 /BOT/<BotID>，保存文档在该工作区的 documents/；不要修改活跃内部注册表，也不要读取或外泄宿主内部数据、凭据。
