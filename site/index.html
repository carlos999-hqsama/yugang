鱼缸

English

一个基于 DeepSeek Agent Harness 的开源 Android App。可以和 Bot 聊天，也可以让 Bot 帮你做插件，把常用的工具装进手机。

为什么叫鱼缸？

DeepSeek 的形象是一只鲸鱼。那就把主 Bot 当作缸里的大鲸鱼，其他 Bot 当作各有分工的小鱼。

每条鱼有自己的工作区，放自己的提示词、记忆、聊天归档和工具配置。它们继承一套共同人格，也可以互相传消息、分工做事。

插件就像鱼缸里的置景。你需要什么，就往里面布置什么。有人放效率工具，有人放阅读和内容插件，每个人最后养出来的鱼缸都不一样。

怎么用？

比如，你想做一个自己用的小工具：

  1. 先和主 Bot 聊，把想法和需求捋清楚。
  2. 让主 Bot 把需求交给插件 Bot，插件 Bot 负责实现。
  3. 插件 Bot 通过独立预览通道检查页面和功能，不用切走你正在看的页面。
  4. 做完后把结果告诉主 Bot，再检查一遍；装好的插件就能在菜单里使用。

第一次使用时，左侧“插件”入口会带你找到插件 Bot；可以点“AI 新闻”示例，修改需求后发送。Agent 实际做完并安装后，新插件会替换这个空入口。

不写插件也可以。给不同 Bot 分配不同职责，让它们各自管理资料，照常聊天和处理任务就行。模型账号需要自己配置：先填写 Key，验证并获取可用模型后再选择模型。业务插件不预装。

目前有什么

  • 多 Bot 对话、独立工作区；上下文在运行时按需组装：共同人格单一来源继承，身份、职责、记忆和工具按当前配置加入，不靠一份复制出来的固定长提示词。
  • Bot 之间传递、读取消息，内部管理历史和归档。
  • 文件、命令、网页工具，以及反馈和执行交替展示的任务过程。
  • 独立插件的安装、启停、删除，切换页面保留状态。
  • 插件共用的页面组件、黑白主题、网络、流式请求、模型与翻译能力。
  • 草稿离屏预览、截图、后台计划、通知、媒体和原生 TTS。

架构

分成两部分：

  • Agent Harness：基于 DeepSeek Agent Harness 二次开发，处理对话、上下文、工具调用和 Bot 协作。
  • 插件底座：Android 宿主提供公共框架和通用能力，插件只负责自己的功能、页面和设置。
鱼缸 App
├─ 对话与 Bot
│  ├─ 共同人格 + 各自职责
│  └─ 独立工作区、记忆与归档
├─ 本地 Agent Harness
└─ Android 插件宿主
   ├─ 公共页面框架与通用能力
   └─ 用户自己安装的插件

模型推理使用你配置的服务；“本地 Harness”不表示模型在手机上离线推理。详细分层、上下文流程、数据归属和取消边界见 架构说明。

共同人格的手动设置和记忆学习结果分开保存，下一次回复动态组装；插件可以定义自己的场景风格。Core 提供候选校验、存储和组装，记忆来源与夜间反思由独立适配器负责。

开源范围

公开的是对话和完整通用底座。插件用得到的文件、联网、模型、媒体、预览、后台等能力保留真实实现。

业务插件、私人伴侣服务、远端业务连接和 Token、私人配置和历史数据不包含在公开工程里。账号、聊天、记忆、附件、已安装插件和签名密钥也不包含在源码或 APK 中。分享 APK，不会把你养的鱼和布置的插件一起分享出去。演示中出现的业务插件（如 Tibo、Codex、B 站相关插件）都不是预置 Core，公开工程不携带它们。

具体剥离范围见 CORE_SPLIT.md。

运行与构建

Android 10+，ARM64。后台执行会受系统电池策略影响。

构建需要 JDK 17、Android SDK、Python 和 Node.js，并按锁文件准备运行时。官方固定输入的下载地址可能失效，公开源已附带 3 份上游原始 DEB、匹配完整源码和 Termux 构建配方（约 11.7 MB），构建时按锁文件和 SHA-256 摘要校验，不用本机编译产物代替。完整步骤见 BUILD.md，插件写法见 宿主接口说明。

当前状态

这是可以审阅的源码候选，尚未正式发布。

  • 构建成功不代表真机可用。离线测试与 Debug/Release 构建命令见 BUILD.md；ARM64 手机上的首启、运行时初始化、后台驻留、通知和插件安装需要单独验收。
  • 此前在 ARM64 Android 手机上完成过一次首启、运行时初始化与重启验收。本轮有效账号的模型连通测试按用户要求跳过，新插件引导和图片修复的真机检查仍待补；私人全量版的验收不能代替公开 Core 的验收。
  • 已在独立 Linux 环境完成最终源码的干净重建、167 项单元检查、Release lint 和 R8；初始缓存为空，最终仅复用本轮 Linux 下载的依赖，不复制 Mac 构建结果。后续改动需对应版本复测。官方固定 PRoot DEB 下载地址已 404，公开源保留原锁定版本的原始输入并做摘要校验；第三方组件与对应源码见 第三方声明。

安全

PRoot、Bot 工作区和能力声明不是恶意代码沙箱。插件和 Agent 工具共享 App 身份，只安装你审阅并信任的代码。宿主加密保存凭据，接口不返回 Key，但这不代表同身份恶意代码就安全。详见 SECURITY.md。

许可与参与

宿主源码使用 GPL-3.0-only。第三方组件保留各自许可证，分发二进制时附上匹配的许可正文和所需对应源码。见 第三方声明。

YuGang (鱼缸)

中文

An open-source Android App built on DeepSeek Agent Harness. Chat with Bots, or let them help build plugins that turn your ideas into tools on your phone.

Why “YuGang”?

“YuGang” means fish tank. DeepSeek is represented by a whale, so think of your main Bot as the big whale and the other Bots as smaller fish with their own jobs.

Each Bot has a workspace for its role prompt, memory, chat archives and tool settings. They share a common persona and can exchange messages to work together.

Plugins are the things you add to the tank. Add a productivity tool, a reading tool or something else you need. Everyone ends up with a different environment.

How would I use it?

Say you want a small tool for yourself:

  1. Talk through the idea with the main Bot.
  2. Ask it to pass the requirements to the plugin Bot for implementation.
  3. The plugin Bot checks the page and behavior through an offscreen preview channel, without switching your foreground page.
  4. It reports back to the main Bot for another check. Once installed, the plugin is available from the menu.

On first use, the Plugins entry takes you to the plugin Bot. Choose the AI News example, edit the request and send it. Once the Agent actually builds and installs a plugin, that plugin replaces the empty entry.

You do not have to build plugins. Give Bots different roles and let them manage their own material while you chat and work. Bring your own model account: enter a key, validate it and retrieve available models before choosing one. Business plugins are not preinstalled.

What is included

  • Multi-Bot chat and separate workspaces. Context is assembled at runtime: a single-source shared persona is inherited, and identity, roles, memory and tools are added per current configuration instead of one copied fixed prompt.
  • Messages between Bots, with history and archives managed internally.
  • File, shell and web tools, with progress updates interleaved with execution.
  • Independent plugin installation, enable/disable and removal, with page state retained across menu switches.
  • Shared page components, monochrome styling, network/streaming requests, models and translation.
  • Draft offscreen preview, screenshots, background jobs, notifications, media and native TTS.

Architecture

There are two parts:

  • Agent Harness: adapted from DeepSeek Agent Harness for conversations, context, tool calls and Bot collaboration.
  • Plugin foundation: the Android host supplies the shared framework and general capabilities. Plugins provide their own features, pages and settings.
YuGang App
├─ Conversation and Bots
│  ├─ Shared persona + individual roles
│  └─ Separate workspaces, memory and archives
├─ Local Agent Harness
└─ Android plugin host
   ├─ Shared page framework and general capabilities
   └─ Independently installed plugins

Model inference uses your configured service. “Local Harness” does not mean offline model inference on the phone. See ARCHITECTURE.md for layers, context assembly, data ownership and cancellation.

Manual persona settings and structured learned tendencies are stored separately and composed for subsequent replies. Plugins own their scene-specific style. Core validates, stores and composes candidates; memory sources and nightly reflection belong to separate adapters.

What is open source?

The public source includes conversation and the complete general foundation. Real implementations for files, networking, model access, media, preview and background work remain available.

Business plugins, private companion services, remote business connections and tokens, private configuration and history are excluded. Accounts, chats, memory, attachments, installed plugins and signing keys are not included in source or APK exports. Sharing the APK does not share your personal environment. Business plugins seen in demos (such as Tibo, Codex or Bilibili-related plugins) are not preinstalled Core and are not shipped here.

See CORE_SPLIT.md for the boundary.

Run and build

Android 10+, ARM64. OS battery policy can affect background work.

Build with JDK 17, the Android SDK, Python and Node.js, preparing the runtime from pinned inputs. Upstream download URLs can disappear, so the public source ships the three original DEBs, matching complete source and the Termux build recipe (about 11.7 MB); builds verify them against lockfiles and SHA-256 digests instead of substituting locally compiled output. See BUILD.md and the host API contract.

Current status

This is a source candidate for review, not an officially published release.

  • A successful build is not proof of a working device. Offline tests and Debug/Release build commands are in BUILD.md; first boot, runtime initialization, background behavior, notifications and plugin installation on an ARM64 phone need separate acceptance.
  • A previous round verified first boot, runtime initialization and restart on an ARM64 Android phone. This round skips valid-account model discovery at the user's request; physical-device checks for the new plugin guide and the image fix are still pending. Acceptance of the private full App does not replace public Core acceptance.
  • The final source passed a clean Release rebuild, 167 unit checks, Release lint and R8 in an independent Linux environment. Caches were initially empty; only dependencies downloaded by that Linux environment were reused, without Mac build outputs. Future changes need version-specific checks. The pinned upstream PRoot DEB URL now returns 404; the public source keeps the originally pinned inputs with digest verification. See THIRD_PARTY_NOTICES.md for components and corresponding source.

Security

PRoot, Bot directories and capability declarations are not a hostile-code sandbox. Plugins and Agent tools share the App identity. Install only code you have reviewed and trust. The host encrypts stored credentials and does not return keys through plugin APIs, but this does not make malicious same-identity code safe. See SECURITY.md.

License and contributions

Host source is GPL-3.0-only. Third-party components retain their own licenses. Binary distributions need matching license texts and required corresponding source. See THIRD_PARTY_NOTICES.md.

Issues and improvements are welcome. Read CONTRIBUTING.md first, and keep private data and secrets out of issues.
